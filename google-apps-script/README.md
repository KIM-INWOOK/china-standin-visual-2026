# 구글 시트 댓글 연결

Code.gs를 Apps Script 프로젝트에 붙여넣고 저장합니다. 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자는 본인, 액세스 권한은 모든 사용자로 설정합니다. 권한 승인 후 끝이 /exec인 웹 앱 URL을 프런트엔드에 연결해야 합니다. 프로젝트 편집 URL은 API 주소가 아닙니다.

첫 정상 제출 시 지정된 스프레드시트에 독자의견 탭을 만듭니다. 기존 다른 탭은 수정하지 않습니다. 공개여부를 비공개로 바꾸면 조회에서 제외됩니다. 공개되는 값은 의견 내용, 금액, 작성시간, 식별번호입니다. 시트 자체를 공개할 필요는 없습니다.

현재 프런트엔드는 기존 /api/opinions를 사용합니다. 실제 웹 앱 URL 수령 후 연결 수정과 브라우저 저장·조회 검증이 필요합니다. 입력 제한·동시 쓰기 잠금·같은 내용의 60초 중복 제한은 포함돼 있지만 CAPTCHA 또는 강력한 도배 방지는 포함하지 않습니다. Apps Script 할당량과 계정 정책에 따라 사용이 제한될 수 있습니다.
